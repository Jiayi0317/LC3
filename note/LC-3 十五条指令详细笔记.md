# LC-3 十五条指令详细笔记

> 说明：以下每条指令都给出 **格式（汇编写法）**、**机器码字段**、**执行语义**、**实现过程**、**示例**。你已会的 ADD/AND/NOT/BR 也一并按此格式补充，便于统一对照。

---

## 一、运算类指令

### **1. ADD 指令**

ADD 用于加法运算。有两种形式。

**寄存器形式：**

```
ADD DR, SR1, SR2
```

机器码：`0001 DR SR1 000 SR2`

表示：

\[ DR = SR1 + SR2 \]

例如：

```
ADD R3, R1, R2
```

表示：

\[ R3 = R1 + R2 \]

**立即数形式：**

```
ADD DR, SR1, imm5
```

机器码：`0001 DR SR1 1 imm5`

表示：

\[ DR = SR1 + imm5 \]

例如：

```
ADD R3, R0, #5
```

表示：

\[ R3 = R0 + 5 \]

这里的 `#5` 表示十进制 5。

**imm5 的含义**：5 位有符号补码数，取值范围 \(-16 \leq imm5 \leq 15\)。立即数在参与运算前会**符号扩展**到 16 位。

**实现过程**：
1. 读出 SR1 的值。
2. 若为寄存器形式，读出 SR2；若为立即数形式，将 imm5 符号扩展为 16 位。
3. 两数送入 ALU 做加法。
4. 结果写入 DR，同时根据结果更新 NZP 条件码。

---

### **2. AND 指令**

AND 用于按位与运算。有两种形式。

**寄存器形式：**

```
AND DR, SR1, SR2
```

机器码：`0101 DR SR1 000 SR2`

表示：

\[ DR = SR1 \ \&\ SR2 \]

例如：

```
AND R3, R1, R2
```

表示：

\[ R3 = R1 \ \&\ R2 \]

**立即数形式：**

```
AND DR, SR1, imm5
```

机器码：`0101 DR SR1 1 imm5`

表示：

\[ DR = SR1 \ \&\ imm5 \]

例如：

```
AND R3, R0, #15
```

表示：

\[ R3 = R0 \ \&\ 15 \]

**典型用途**：
- **清零**：`AND R0, R0, #0`，R0 与 0 相与结果为 0。
- **取某几位（掩码）**：`AND R1, R1, #15` 只保留低 4 位，其余位清零。

**实现过程**：与 ADD 类似，区别是 ALU 执行按位与，且立即数同样先符号扩展到 16 位（做掩码时通常用正数，符号扩展不影响低 5 位）。

---

### **3. NOT 指令**

NOT 用于按位取反，是唯一的一元运算。

**格式：**

```
NOT DR, SR
```

机器码：`1001 DR SR 111111`（末 6 位固定为 `111111`）

表示：

\[ DR = \overline{SR} \]

例如：

```
NOT R2, R1
```

表示：

\[ R2 = \overline{R1} \]

**注意**：NOT **没有立即数形式**，操作数必须是寄存器。

**取负（求补）的常用组合**：

```
NOT R1, R1
ADD R1, R1, #1
```

即 \( R1 = -R1 \)（补码意义下取相反数）。

**实现过程**：读出 SR 的值，ALU 按位取反，结果写入 DR 并更新 NZP。

---

## 二、数据搬移类指令

### **4. LD 指令（直接载入，PC 相对寻址）**

LD 从内存读数据到寄存器，地址由 **PC + 偏移** 算出。

**格式：**

```
LD DR, LABEL
```

机器码：`0010 DR PCoffset9`

表示：

\[ DR = Mem[PC + \text{SEXT}(PCoffset9)] \]

其中 PC 是**已自增后**的当前指令地址（即下一条指令地址），SEXT 表示符号扩展。

例如：

```
LD R1, VALUE
...
VALUE .FILL x1234
```

若 `LD` 位于地址 x3000，则执行时 PC 已变为 x3001，汇编器算出 `PCoffset9 = VALUE - x3001`，运行时：

\[ R1 = Mem[x3001 + PCoffset9] = Mem[VALUE] = x1234 \]

**PCoffset9 的含义**：9 位有符号补码，范围 \(-256 \leq offset \leq 255\)，即只能访问距当前指令约 ±256 字范围内的内存。

**实现过程**：
1. PC 已自增。
2. 将 PCoffset9 符号扩展为 16 位。
3. 与 PC 相加得到有效地址。
4. 读该地址内容写入 DR，更新 NZP。

---

### **5. ST 指令（直接存储，PC 相对寻址）**

ST 把寄存器值写入内存，寻址方式与 LD 相同。

**格式：**

```
ST SR, LABEL
```

机器码：`0011 SR PCoffset9`

表示：

\[ Mem[PC + \text{SEXT}(PCoffset9)] = SR \]

例如：

```
ST R2, RESULT
...
RESULT .BLKW 1
```

表示把 R2 的值写入 `RESULT` 所在内存单元。

**实现过程**：算出 PC + 符号扩展偏移得到地址，把 SR 写入该地址。**注意 ST 不修改任何寄存器，因此不更新条件码**（条件码只在写寄存器时更新）。

---

### **6. LDI 指令（间接载入）**

LDI 做**两次访存**：先读出一个地址，再按该地址读数据。

**格式：**

```
LDI DR, LABEL
```

机器码：`1010 DR PCoffset9`

表示：

\[ DR = Mem[\ Mem[PC + \text{SEXT}(PCoffset9)]\ ] \]

例如：

```
LDI R1, PTR
...
PTR .FILL x4000
```

执行时：
1. 先算 `PC + PCoffset9` 定位到 `PTR`，读出其中的 x4000；
2. 再读 `Mem[x4000]`，把结果放入 R1。

**用途**：当目标数据距离当前指令超过 ±256 字时，用 LDI 借助一个“指针单元”间接访问远处内存。

**实现过程**：
1. PC 自增，加符号扩展偏移得地址 A。
2. 读 `Mem[A]` 得到地址 B。
3. 读 `Mem[B]` 写入 DR，更新 NZP。

---

### **7. STI 指令（间接存储）**

STI 是 LDI 的逆操作，同样两次访存。

**格式：**

```
STI SR, LABEL
```

机器码：`1011 SR PCoffset9`

表示：

\[ Mem[\ Mem[PC + \text{SEXT}(PCoffset9)]\ ] = SR \]

例如：

```
STI R2, PTR
...
PTR .FILL x4000
```

表示把 R2 的值写入 `Mem[x4000]`。

**实现过程**：先算出指针单元地址并读出目标地址 B，再把 SR 写入 `Mem[B]`。不更新条件码。

---

### **8. LDR 指令（基址 + 偏移载入）**

LDR 用一个**基址寄存器**加 6 位偏移来定位内存。

**格式：**

```
LDR DR, BaseR, offset6
```

机器码：`0110 DR BaseR offset6`

表示：

\[ DR = Mem[BaseR + \text{SEXT}(offset6)] \]

例如遍历数组：

```
LEA R2, ARRAY      ; R2 = 数组首地址
LDR R1, R2, #0     ; R1 = ARRAY[0]
LDR R3, R2, #1     ; R3 = ARRAY[1]
```

**offset6 的含义**：6 位有符号补码，范围 \(-32 \leq offset \leq 31\)。基址寄存器里存的是**地址**，不是数据。

**实现过程**：
1. 读 BaseR 的值。
2. offset6 符号扩展为 16 位后与 BaseR 相加得有效地址。
3. 读该地址写入 DR，更新 NZP。

---

### **9. STR 指令（基址 + 偏移存储）**

STR 与 LDR 对称，把寄存器写入 `BaseR + offset6` 指向的内存。

**格式：**

```
STR SR, BaseR, offset6
```

机器码：`0111 SR BaseR offset6`

表示：

\[ Mem[BaseR + \text{SEXT}(offset6)] = SR \]

例如：

```
LEA R2, ARRAY
STR R1, R2, #0     ; ARRAY[0] = R1
STR R1, R2, #1     ; ARRAY[1] = R1
```

**实现过程**：算地址 `BaseR + 符号扩展(offset6)`，写入 SR。不更新条件码。

---

### **10. LEA 指令（载入有效地址）**

LEA 只**计算地址**并放入寄存器，**不访问内存**。

**格式：**

```
LEA DR, LABEL
```

机器码：`1110 DR PCoffset9`

表示：

\[ DR = PC + \text{SEXT}(PCoffset9) \]

例如：

```
LEA R2, ARRAY
```

执行后 R2 里就是 `ARRAY` 的地址，而不是 `ARRAY` 处的内容。常配合 LDR/STR 使用。

**与 LD 的关键区别**：
- `LD R2, ARRAY` → R2 = `Mem[ARRAY]`（读内容）
- `LEA R2, ARRAY` → R2 = `ARRAY`（得地址）

**实现过程**：PC 自增后加符号扩展偏移，结果写入 DR，更新 NZP。

---

## 三、控制转移类指令

### **11. BR 指令（条件跳转）**

BR 根据 NZP 条件码决定是否跳转。

**格式：**

```
BRn LABEL
BRz LABEL
BRp LABEL
BRnz LABEL   ; 可组合
```

机器码：`0000 n z p PCoffset9`

表示：若条件码满足（n/z/p 中对应位为 1 且当前 NZP 匹配），则

\[ PC = PC + \text{SEXT}(PCoffset9) \]

否则 PC 保持自增后的值（顺序执行）。

例如：

```
ADD R1, R1, #-1
BRp LOOP      ; 若 R1 > 0（结果为正，N=0 Z=0 P=1）则跳回 LOOP
```

**要点**：
- 条件码 N/Z/P 由**最近一次写寄存器的指令**设置（ADD、AND、NOT、LD、LDR、LDI、LEA 等）。
- BR 本身不修改条件码。
- 无条件跳转写作 `BR`（nzp 全 0 时永不跳，实际无条件跳转用 `BRnzp`）。

**实现过程**：检查指令中 n/z/p 位与当前条件码，若任一指定条件成立则 PC 加符号扩展偏移，否则 PC 已自增、继续执行。

---

### **12. JMP 指令（寄存器跳转）**

JMP 无条件把 PC 设为某寄存器的值。

**格式：**

```
JMP BaseR
```

机器码：`1100 000 BaseR 000000`

表示：

\[ PC = BaseR \]

例如：

```
JMP R3
```

**RET 是伪指令**：`RET` 等价于 `JMP R7`，用于从子程序返回（R7 存着返回地址）。

**实现过程**：把 BaseR 的值直接装入 PC。不修改条件码。

---

### **13. JSR 指令（跳转至子程序，PC 相对）**

JSR 调用子程序：先把返回地址存入 R7，再跳转。

**格式：**

```
JSR LABEL
```

机器码：`0100 1 PCoffset11`

表示：

\[ R7 = PC \quad（保存返回地址） \]
\[ PC = PC + \text{SEXT}(PCoffset11) \]

例如：

```
JSR SUB
...
SUB ADD R1, R1, #1
    RET            ; 即 JMP R7，返回 JSR 的下一条
```

**PCoffset11 的含义**：11 位有符号补码，范围约 \(-1024 \leq offset \leq 1023\)，比 BR/LD 的 9 位范围更大。

**实现过程**：
1. PC 已自增，把该值（返回地址）写入 R7。
2. PC 加符号扩展的 PCoffset11 得到子程序入口。
3. 子程序末尾用 `RET`（JMP R7）返回。

---

### **14. JSRR 指令（跳转至子程序，寄存器基址）**

JSRR 与 JSR 功能相同，但目标地址来自寄存器。

**格式：**

```
JSRR BaseR
```

机器码：`0100 000 BaseR 000000`

表示：

\[ R7 = PC \]
\[ PC = BaseR \]

例如：

```
JSRR R3
```

适合函数指针、跳转表等目标地址在运行时才确定的场景。

**实现过程**：PC 自增后写入 R7，再把 BaseR 装入 PC。不修改条件码（R7 的写入按惯例不视为影响 NZP 的判断依据，实际硬件中写 R7 也会更新条件码，编程时需注意）。

---

### **15. TRAP 指令（系统调用）**

TRAP 用于调用操作系统例程（如输入输出、停机）。

**格式：**

```
TRAP trapvect8
```

机器码：`1111 0000 trapvect8`

表示：

\[ R7 = PC \]
\[ PC = Mem[\text{ZEXT}(trapvect8)] \]

即用 8 位陷阱向量（零扩展）查中断向量表，跳到对应服务例程。

**常用别名**：

| 别名    | 等价       | 功能                     |
| ------- | ---------- | ------------------------ |
| `HALT`  | `TRAP x25` | 停机                     |
| `GETC`  | `TRAP x20` | 读一个字符到 R0          |
| `OUT`   | `TRAP x21` | 输出 R0 中的字符         |
| `PUTS`  | `TRAP x22` | 输出字符串               |
| `IN`    | `TRAP x23` | 读字符并回显             |
| `PUTSP` | `TRAP x24` | 输出字符串（每字两字符） |

例如：

```
LEA R0, MSG
PUTS           ; 输出 MSG 指向的字符串
HALT
```

**实现过程**：
1. PC 自增后写入 R7（保存返回地址）。
2. 零扩展 trapvect8 作为地址，读 `Mem[trapvect8]` 得到服务例程入口。
3. 装入 PC，进入系统例程；例程结束时用 `JMP R7` 返回。

---

## 四、两条非指令说明

- **RTI（opcode 1000）**：LC-3 中**未使用**，仅保留编码。
- **opcode 1101**：保留，未定义，遇到即非法指令。

## 五、快速对照表

| Opcode | 助记符   | 格式                                 | 访存次数      | 一句话                   |
| ------ | -------- | ------------------------------------ | ------------- | ------------------------ |
| 0000   | BR       | `BRn/z/p LABEL`                      | 0             | 条件跳转                 |
| 0001   | ADD      | `ADD DR,SR1,SR2` / `ADD DR,SR1,imm5` | 0             | 加法                     |
| 0010   | LD       | `LD DR,LABEL`                        | 1             | PC相对读                 |
| 0011   | ST       | `ST SR,LABEL`                        | 1             | PC相对写                 |
| 0100   | JSR/JSRR | `JSR LABEL` / `JSRR BaseR`           | 0             | 调子程序，R7 存返回地址  |
| 0101   | AND      | `AND DR,SR1,SR2` / `AND DR,SR1,imm5` | 0             | 按位与                   |
| 0110   | LDR      | `LDR DR,BaseR,offset6`               | 1             | 基址+偏移读              |
| 0111   | STR      | `STR SR,BaseR,offset6`               | 1             | 基址+偏移写              |
| 1000   | RTI      | —                                    | —             | 未使用                   |
| 1001   | NOT      | `NOT DR,SR`                          | 0             | 按位取反                 |
| 1010   | LDI      | `LDI DR,LABEL`                       | 2             | 间接读                   |
| 1011   | STI      | `STI SR,LABEL`                       | 2             | 间接写                   |
| 1100   | JMP      | `JMP BaseR`                          | 0             | 寄存器跳转（RET=JMP R7） |
| 1101   | —        | —                                    | —             | 保留                     |
| 1110   | LEA      | `LEA DR,LABEL`                       | 0             | 算地址不读内存           |
| 1111   | TRAP     | `TRAP trapvect8`                     | 0（查向量表） | 系统调用                 |

**记忆抓手**：搬移类看“访存几次、地址怎么来”（PC相对 1 次 / 间接 2 次 / 基址+偏移 1 次 / LEA 0 次）；控制类看“返回地址存哪”（JSR/JSRR/TRAP 都存 R7，JMP 不存）；写寄存器的指令更新 NZP，纯写内存的 ST/STR/STI 不更新。
