## 2 问题描述
矩阵转置是一种将矩阵沿其对角线翻转的操作，交换矩阵的行索引和列索引。对于$N \times N$方阵$A$，转置$A^T$定义为：
$$A^{T} [ c ] [ r ] = A [ r ] [ c ] \tag{1}$$

在本实验中，你将处理一个以行主序存储在连续内存位置中的方阵。你的任务是编写一个LC-3汇编程序，就地转置该矩阵。

### 2.1 内存布局
矩阵维度和数据的存储方式如下：
- x30FF：矩阵大小$i$（$i \times i$方阵的维度，其中$2 \leq i \leq 8$）
- x3100起：按行主序存储的矩阵元素（共$i^2$个元素）

对于$i \times i$矩阵，元素$A[r][c]$存储在地址：
$$ \text{Address}(A[r][c]) = x3100 + (r \times i + c) \quad (2) $$
其中$0 \le r < i$且$0 \le c < i$。

你的程序必须从内存中读取维度，就地转置矩阵，并将结果写回从x3100开始的相同内存位置。

## 4 参考方法

### 4.1 实现步骤
1. 从x30FF加载矩阵维度$i$。
2. 将基址寄存器初始化为x3100（矩阵的起始地址）。
3. 对于$r = 0$到$i - 2$：
   - 对于$c = r + 1$到$i - 1$：
     - 计算$A[r][c]$的地址：$addr = x3100 + (r \times i + c)$
     - 将$A[r][c]$加载到寄存器
     - 计算$A[c][r]$的地址：$addr = x3100 + (c \times i + r)$
     - 将$A[c][r]$加载到寄存器
     - 将$A[c][r]$存储到$A[r][c]$的位置
     - 将$A[r][c]$存储到$A[c][r]$的位置
4. 暂停程序。

### 4.2 观察
在汇编中访问二维数组元素时，地址计算遵循公式2。在LC-3中，每个元素占用一个16位字，内存按字寻址，因此除了公式2已经给出的内容外，不需要额外按元素大小进行缩放。

由于LC-3没有乘法指令，你需要通过重复加法来实现$r \times i$，或者更高效地，通过维护一个运行中的行基址：不是每次为每个元素从头重新计算$r \times i$，而是保持一个寄存器保存当前行起始地址，并在每次$r$递增时向其加上$i$。在行内，你可以通过将$c$加到这个行基址上来到达$A[r][c]$。

注意，LDR/STR指令的偏移范围是6位有符号offset6字段，范围为-32到+31。对于小到$i = 6$的矩阵，这个范围就已经被超出了（例如，$A[5][5]$需要偏移35）。你不应该对每次访问都依赖固定的小偏移——相反，在寄存器中计算完整的目标地址（使用ADD）并以0偏移访问内存，或者在遍历矩阵时增量更新基址寄存器。

### 4.3 非方阵（报告中可选）
如果矩阵不是方阵（即$i \times j$，其中$i \neq j$），转置操作会将矩阵维度变为$j \times i$。在这种情况下，就地转置变得显著复杂，因为：
- 原矩阵中的元素$A[r][c]$需要移动到转置矩阵中的位置$A'[c][r]$，但$j \times i$矩阵的内存布局与$i \times j$矩阵不同。
- 直接交换方法行不通，因为源位置和目标位置可能以非平凡的方式重叠。
- 一种方法是使用临时缓冲区存储转置后的矩阵，然后将其复制回原始位置。
- 另一种方法是使用循环跟踪算法，跟踪哪些元素已被移动，以避免过早覆盖数据。
