## 2，实验思路

通过**if-else**的分支来实现奇偶转化，用ADD的指令，通过加0以实现R0的赋值

首先判断奇偶性，由于奇数补码最后一位肯定是1，所以通过and语句，和1进行与运算。若得到1，说明奇数，0说明偶数

代码实现是 

```asm
# 机器码(二进制)     		汇编指令
0101 011 000 1 00001    AND R3, R0, #1   //R3 = R1 & 1 用R3来判断奇偶性，0偶，1奇

```

然后根据之前的指令得到的条件码

**0-偶数-z           1-奇数-p**

进行下面的判断,根据计算得到指令 **PCoffset9（PC-relative Offset 9）**应该为2

```asm
0000 010 000000010      BRz EVEN       //如果z(上一个结果为0)，跳转EVEN(PC自增后加2)
```

如果没有跳转，就是奇数，进行运算

不过运算之后记得结束（通过nzp无条件(注意PCoffset9计算)跳出）**不然会继续进行偶数的运算！**

```asm
0001 000 010 1 00000    ADD R0, R2, #0  //(不是偶数)，R0 = R2 +0  
0000 111 000000001      BRnzp DONE      //跳转到done，(自增后加一)
```

然后是偶数的处理

最后结束

```asm
0001 000 001 00000      ADD R0, R1, #0  //(是偶数),R0 = R1 +0 
1111 0000 00100101      HALT            //结束
```

## 3,完整代码实现

```asm
0101 011 000 1 00001    AND R3, R0, #1 		//R3 = R1 & 1 用R3来判断奇偶性，0偶，1奇
0000 010 000000010      BRz EVEN       		//如果z(上一个结果为0)，跳转EVEN(PC自增后加2)
0001 000 010 1 00000    ADD R0, R2, #0		//(不是偶数)，R0 = R2 +0  
0000 111 000000001      BRnzp DONE     		//跳转到done，(自增后加一)
0001 000 001 00000      ADD R0, R1, #0  	//(是偶数),R0 = R1 +0 
1111 0000 00100101      HALT           		//结束
```
